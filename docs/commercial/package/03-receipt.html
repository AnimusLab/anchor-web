Secure onboarding

The authorised signatory receives a private, single-use invitation link of the form https://hub.animuslab.dev/onboard#token=<ONE_TIME_INVITATION_TOKEN>. The token is stored only as a SHA-256 hash, expires within a configurable window, and is consumed atomically.

The onboarding invitation is a separate credential from the licence manifest. It is not the Ed25519 licence key, and it carries its own expiry, revocation and audit lifecycle.
