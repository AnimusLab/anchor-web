Order of precedence

Conflict rule

If documents conflict, the following order applies:

  1. Order Form — as to commercial terms only (parties, term, quantities, fees).
  2. DPA — as to personal data.
  3. MSA — as to all other legal terms.
  4. SLA — as to availability and support.
  5. Security Schedule — as to technical and organisational measures.
  6. Acceptable Use Policy — as to permitted use.

A term in a customer purchase order, supplier portal or vendor form has no effect, even if signed or accepted electronically.

C

Package conventions

How to read this set

Commercial documents

The Order Form is the commercial layer and is intentionally short. The Tax Invoice and Receipt are financial documents issued after execution and settlement. They do not vary the agreement.

Document integrity

No document prints its own SHA-256. The executed PDF hash is recorded in a detached signing certificate and in the e-signature audit record. A hash printed inside a document cannot be verified against that same document.

Executed copies and their detached integrity certificate are retained by AnimusLab's contract system. Verify a copy by recomputing SHA-256 over the exact file bytes and comparing it with the certificate.
