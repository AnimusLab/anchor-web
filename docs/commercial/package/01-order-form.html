08

Activation sequence

Signing does not grant production access

Execution starts a controlled sequence. Production access is granted only after every step completes.

  1. Contract executed — this Order Form and the incorporated MSA are signed.
  2. Invoice issued — the Tax Invoice is issued for the full term.
  3. Payment received — cleared funds, or credit approved in writing.
  4. Entitlements activated — the Entitlement Manifest is signed and grants become active.
  5. Hub provisioned — the dedicated Hub is deployed in the contracted region.
  6. Invitation issued — a single-use onboarding token is delivered privately to the authorised signatory.
  7. Onboarding complete — the Hub Manager enrols an authenticator and the Hub goes live.
The licence manifest and the onboarding credential have independent security lifecycles. The manifest is an Ed25519-signed capacity record; the onboarding token is a separate, short-lived, SHA-256-hashed secret that is never logged and is consumed atomically.
